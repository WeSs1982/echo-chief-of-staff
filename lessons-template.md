# Lessen

Regels die voortkomen uit beslissingen. Elke les is een zin die het team de volgende keer niet vergeet.

## Actuele lessen
1. (Voorbeeld) Beslissingen zonder uitkomst zijn waardeloos — altijd een resultaat-regel toevoegen.
2. (Voorbeeld) Stilte van een bot is een signaal, geen rust.

## Hoe een les toe te voegen
- Komt uit een entry in `decisions-log.md`.
- Eén zin, concreet, zonder uitleg.
- Verwijder een les pas als hij vervangen is door een betere.
